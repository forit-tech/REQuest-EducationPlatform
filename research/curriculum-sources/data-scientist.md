# Источники: вводный этап Data Scientist

Исследование проведено для перестройки первого этапа маршрута (технический фундамент
и начало Python). Программы не копировались: из них извлекалась только последовательность
тем и педагогические приёмы.

## CS50x — Harvard University

- URL: https://cs50.harvard.edu/x/syllabus/
- Организация: Гарвардский университет, факультет компьютерных наук.
- Порядок недель: Scratch → C → массивы → алгоритмы → память → структуры данных →
  Python → SQL → HTML/CSS/JavaScript → Flask.

**Что взято как curriculum insight.** Нулевая неделя — Scratch, визуальная среда без
синтаксиса. Курс сознательно откладывает написание кода: сначала выстраивается модель
«программа как последовательность инструкций», и только потом появляется язык. Это прямое
основание для того, чтобы темы про процессор, память и файлы не требовали кода вообще.

**Что не переносилось.** Сам Scratch, порядок языков (C до Python), задания и лекции.
У нас профессиональный маршрут в данные, а не общий вводный курс информатики.

## Python Programming MOOC — University of Helsinki

- URL: https://programming-25.mooc.fi/ и https://programming-25.mooc.fi/part-3
- Организация: Хельсинкский университет, департамент компьютерных наук.
- Часть 1: начало работы → ввод от пользователя → переменные подробнее → арифметика →
  условные конструкции.
- Часть 3: циклы с условием → работа со строками → ещё циклы → **определение функций**.

**Что взято как curriculum insight.** Это самый важный источник для нас. Функции появляются
только в третьей части, после вывода, ввода, переменных, арифметики, условий, строк и циклов.
До этого момента студент уже написал десятки работающих программ. Наш маршрут требовал
`def` и `return` во второй миссии — это расходится с практикой курса, который прошли сотни
тысяч человек.

**Что не переносилось.** Тексты заданий, порядок внутри частей, система оценивания.

## The Missing Semester of Your CS Education — MIT

- URL: https://missing.csail.mit.edu/
- Организация: Массачусетский технологический институт.
- Порядок лекций: обзор и оболочка → инструменты оболочки и скрипты → редакторы →
  обработка данных → окружение командной строки → **система контроля версий** →
  отладка и профилирование → метапрограммирование → безопасность.

**Что взято как curriculum insight.** Терминал идёт до git, а git — до отладки. Инструменты
преподаются отдельно от языка, практическими занятиями, а не через написание программ.
Подтверждает наш порядок «терминал → git» и то, что эти темы не должны проверяться кодом
на Python.

**Что не переносилось.** Vim, tmux, метапрограммирование — для вводного этапа это лишнее.

## Google Data Analytics Professional Certificate

- URL: https://www.coursera.org/professional-certificates/google-data-analytics
- Организация: Google, платформа Coursera.
- Восемь курсов строго по порядку: основы данных → постановка вопроса → подготовка данных →
  обработка → анализ → визуализация → действие.

**Что взято как curriculum insight.** Первый курс целиком без инструментов: роль аналитика,
виды данных, процесс анализа. Инструменты (таблицы, SQL) появляются только в третьем курсе.
Подтверждает, что понятийный слой должен опережать инструментальный.

**Что не переносилось.** Привязка к продуктам Google, кейсы, порядок внутри курсов.

## Microsoft Learn — путь Data Scientist

- URL: https://learn.microsoft.com/en-us/training/career-paths/data-scientist
- Организация: Microsoft.
- Последовательность: базовые понятия данных → основы машинного обучения → проектирование
  и реализация решения на платформе.

**Что взято как curriculum insight.** Разделение на «фундаментальные понятия» и «работа
на платформе» с явной границей. У нас этой границе соответствует переход от Data Scientist
к ML Engineer.

**Что не переносилось.** Привязка к Azure, сертификационные требования.

## Сводка по общим точкам

Во всех пяти программах совпадает следующее:

1. Понятия идут раньше инструмента. Ни одна программа не начинает с редактора кода.
2. Первая практика — узнавание и выбор, а не производство.
3. Функции никогда не появляются в первых уроках языка.
4. Терминал и система контроля версий — отдельная практическая линия, не через код.
5. Проекты и самостоятельные задачи приходят после серии упражнений с опорой.

Расхождения: CS50 начинает с визуального программирования, Helsinki — сразу с текстового
Python; Google даёт таблицы до SQL, Microsoft — сразу облачные сервисы. Для нашего маршрута
взят вариант, ближе к Helsinki: текстовый Python, но с длинной понятийной прелюдией, как
в CS50 и Google.
