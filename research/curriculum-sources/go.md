# Источники: Go

Исследование для отделения языкового ядра от конкурентности.

## A Tour of Go — официальный курс

- URL: https://go.dev/tour/list
- Организация: команда Go, Google.
- Четыре модуля строго по порядку: **Basics** (пакеты, переменные, функции,
  управление потоком, составные типы: структуры, слайсы, карты) → **Methods and
  interfaces** → **Generics** → **Concurrency** (горутины и каналы).

**Что взято как curriculum insight.** Конкурентность — последний модуль официального
курса, четвёртый из четырёх. Ей предшествуют не только переменные и функции, но и
структуры, слайсы, карты, методы и интерфейсы. Горутина без понимания функции и
структуры не изучается нигде.

**Ограничение источника.** Страница со списком уроков отдаётся скриптом, полный
перечень уроков внутри модулей получить не удалось; порядок модулей взят из
описания курса. Поэтому детальный порядок сверялся по второму источнику.

## Go by Example

- URL: https://gobyexample.com/
- Формат: 85 примеров в фиксированном порядке, каждый — работающая программа.
- Порядок начала: hello world → **values → variables → constants** → `for` →
  `if/else` → `switch` → **arrays → slices → maps** → **functions → multiple
  return values** → variadic → closures → recursion → range → pointers → strings
  and runes → **structs → methods → interfaces** → enums → embedding → generics →
  iterators → **errors → custom errors** → **goroutines (28-й) → channels →
  channel buffering → channel synchronization → channel directions → select** →
  timeouts → worker pools → WaitGroups → mutexes.
- `defer` идёт 49-м, после panic; `context` — 81-м.

**Что взято как curriculum insight.** Горутины — двадцать восьмой пример из
восьмидесяти пяти. До них проходят 27 тем языка, включая структуры, методы,
интерфейсы и ошибки. Каналы, буферизация, направления и `select` идут подряд
сразу после горутин — то есть конкурентность образует связную вторую линию,
а не вкраплена в основы.

**Что не переносилось.** Тексты примеров, порядок внутри блоков, темы
стандартной библиотеки (файлы, HTTP, время) — они у нас распределены по
прикладным курсам.

## Решение по нашему маршруту

**Go Core**: пакет и импорт → переменные → `:=` → базовые типы → функции →
несколько возвращаемых значений → условия → циклы → слайсы → карты → структуры →
методы → интерфейсы → ошибки → `defer`.

**Go: конкурентность** отдельным курсом после ядра: горутина → канал →
буферизованный канал → `select` → `context` → отмена.

Оба источника сходятся: конкурентность — последняя тема, а не первая. Текущий
курс `go-core-concurrency` смешивал их в одном названии и не преподавал ни то,
ни другое: во всех 27 миссиях трека стоял один шаблон `buildPlan()` без единой
горутины и канала.
