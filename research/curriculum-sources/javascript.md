# Источники: JavaScript и React

Исследование для разделения языка и фреймворка. Программы не копировались: из них
извлекалась только последовательность тем и место, где появляется самостоятельный код.

## The Modern JavaScript Tutorial (javascript.info)

- URL: https://javascript.info/ и https://javascript.info/first-steps
- Порядок первой части: введение → **основы языка** → качество кода → объекты →
  типы данных → продвинутая работа с функциями → свойства объектов → прототипы →
  классы → обработка ошибок → **промисы и async/await** → генераторы → модули.
- Внутри «основ языка» 18 уроков строго по порядку: hello world → структура кода →
  strict → **переменные → типы данных** → взаимодействие → преобразование типов →
  операторы → сравнения → **условия** → логические операторы → `??` → **циклы** →
  `switch` → **функции** → функциональные выражения → **стрелочные функции**.

**Что взято как curriculum insight.** Стрелочные функции идут семнадцатым уроком, после
обычных функций, а не вместо них. Промисы и `async/await` — одиннадцатая глава части,
после объектов, классов и обработки ошибок. Объекты появляются только после того, как
пройдены переменные, условия, циклы и функции.

**Что не переносилось.** Тексты уроков, задачи, порядок внутри глав, `use strict`
как отдельная тема.

## MDN — Dynamic scripting with JavaScript

- URL: https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting
- Организация: Mozilla, раздел Learn web development.
- Порядок: что такое JavaScript → первое погружение → отладка → **переменные** →
  числа и операторы → строки → методы строк → **массивы** → задача-челлендж →
  **условия** → **циклы** → **функции** → своя функция → возвращаемое значение →
  **события** → всплытие → задача-челлендж → **объекты** → **DOM** → сетевые запросы →
  JSON → задача-челлендж → отладка и обработка ошибок.

**Что взято как curriculum insight.** Совпадает с javascript.info в главном: DOM идёт
девятнадцатым пунктом, после переменных, массивов, условий, циклов, функций и объектов.
Браузерные API — не начало обучения языку, а его продолжение. Между темами регулярно
стоят задачи-челленджи, то есть самостоятельный код появляется не после каждого урока,
а после накопления нескольких конструкций.

**Что не переносилось.** Привязка к вёрстке, конкретные челленджи, порядок статей.

## Официальная документация React

- URL: https://react.dev/learn
- Организация: команда React.
- Документация прямо перечисляет, что читатель уже должен знать: `if...else`,
  циклы `for`, метод массива `map()`, тернарный оператор `?`, логический `&&`,
  конкатенация строк, `export` / `import`. При незнакомом синтаксисе она отправляет
  на MDN и javascript.info.

**Что взято как curriculum insight.** Это прямое основание разделить курсы: React
предполагает знание языка, а не преподаёт его. Курс по React не может быть первым
местом, где человек видит `const`, стрелочную функцию или `map`.

**Что не переносилось.** Структура документации, tic-tac-toe, API-справочник.

## Решение по нашему маршруту

Порядок JavaScript Core: значения и типы → `let` / `const` → выражения и операторы →
условия → циклы → массивы → объекты → доступ к свойствам → функции → параметры →
`return` → стрелочные функции → деструктуризация → spread → модули → промисы →
`async/await`.

Только после этого React: JSX → компоненты → props → состояние → события → хуки →
эффекты → списки → формы → композиция.

Расхождения источников: MDN даёт события до объектов, javascript.info — объекты
раньше и без DOM вообще. Взят вариант ближе к javascript.info: сначала язык целиком,
браузерные API отдельной линией, потому что у нас за DOM отвечает отдельный курс
web-платформы.
