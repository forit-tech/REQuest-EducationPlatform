# REduQuest

Русскоязычная desktop-платформа практического обучения профессиям в IT и работе с данными. Иерархия обучения: **профессия → маршрут → комната → миссия**. Data Scientist — первый наполненный маршрут, но не граница платформы.

## Что реализовано

- персональный DS-маршрут из 8 тематических комнат;
- каталог профессий: Data Scientist, Аналитик данных, ML-инженер, Инженер данных и AI-инженер;
- карта каждой профессии из пяти связанных этапов с учебными блоками и стеком инструментов;
- 23 курса и 1 016 миссий — от технического фундамента и Python до промышленных конвейеров данных;
- состояния прогресса, доступности и блокировки;
- подробный экран комнаты со списком уроков;
- выбор доступной миссии и карточка следующего шага;
- адаптивная тёмная IDE-компоновка.

## Установка одной командой

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1
```

Установщик проверяет окружение (Node.js 20+, npm, git, свободное место), ставит зависимости,
прогоняет проверки контента и учебного графа, собирает веб- и desktop-версию, создаёт ярлыки
и настраивает автообновление. Ключи: `-SkipChecks`, `-NoShortcuts`, `-NoAutoUpdate`.

## Обновление

```powershell
npm run update
```

Скрипт подтягивает изменения из [репозитория](https://github.com/forit-tech/REQuest-EducationPlatform),
переустанавливает зависимости, если изменился `package-lock.json`, пересобирает приложение
и перезапускает его. `npm run update:check` только проверяет, есть ли новые коммиты.

### Автообновление

Desktop-приложение проверяет `origin` через несколько секунд после запуска и дальше раз в шесть
часов. По умолчанию обновление **ставится автоматически при выходе** — сборка не прерывает занятие,
а следующий запуск уже идёт на новой версии. При обнаружении изменений появляется уведомление;
по клику можно обновиться сразу.

Поведение переключается галочкой в диалоге обновления и хранится в `update-settings.json` рядом
с профилем пользователя. Ручная проверка — пункт «Проверить обновления» в меню приложения.

Если git недоступен, каталог не является репозиторием или нет сети — проверка молча пропускается
и запуску не мешает.

## Desktop-приложение

Сборка отдельного Windows-приложения:

```powershell
npm run desktop:pack
```

Готовый файл: `release\REduQuest Desktop\REduQuest.exe`.

На рабочем столе создаются два ярлыка:

- **REduQuest** — запускает desktop-приложение;
- **REduQuest Restart** — завершает только процессы собранного REduQuest и запускает приложение заново.

Повторная установка ярлыков:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-shortcuts.ps1
```
