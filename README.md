# REQuest

Русскоязычная desktop-платформа практического обучения профессиям в IT и работе с данными. Иерархия обучения: **профессия → маршрут → комната → миссия**. Data Scientist — первый наполненный маршрут, но не граница платформы.

## Что реализовано

- персональный DS-маршрут из 8 тематических комнат;
- каталог профессий: Data Scientist, Аналитик данных, ML-инженер, Инженер данных и AI-инженер;
- карта каждой профессии из пяти связанных этапов с учебными блоками и стеком инструментов;
- 23 курса и 1 016 миссий — от технического фундамента и Python до промышленных конвейеров данных;
- состояния прогресса, доступности и блокировки;
- подробный экран комнаты со списком уроков;
- выбор доступной миссии и карточка следующего шага;
- адаптивная тёмная IDE-компоновка.

## Запуск

```bash
npm install
npm run dev
```

Production-проверка:

```bash
npm run build
```

## Локальный аккаунт

При первом запуске создан демонстрационный REQuest ID:

- логин: `alex_data`;
- пароль: `request2026`.

В профиле можно загрузить фото, изменить данные и пароль, привязать почту и Telegram. Профиль, тема, сессия и прогресс сохраняются локально в браузере.

## Desktop-приложение

Сборка отдельного Windows-приложения:

```powershell
npm run desktop:pack
```

Готовый файл: `release\REQuest Desktop\REQuest.exe`.

На рабочем столе создаются два ярлыка:

- **REQuest** — запускает desktop-приложение;
- **REQuest Restart** — завершает только процессы собранного REQuest и запускает приложение заново.

Повторная установка ярлыков:

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install-shortcuts.ps1
```
