# Производственный бриф: перерисовка актёрского состава в высоком разрешении (v4)

## Зачем

Сцена выводит спрайт высотой до 900 CSS-пикселей (`.vn-sprite` в `src/story/story.css`).
На экране с масштабом Windows 150% это 1350 физических пикселей. В нынешних файлах
фигура занимает 510–715 пикселей: браузер растягивает её в 1.8–2.4 раза, поэтому герои
мылятся, а лица теряют черты — на лицо приходится около 40 пикселей исходных данных.

Причина в способе производства: пять поз рисовались одним листом 1254×1254, и на позу
доставалась четверть листа. Разрешение листа — потолок качества, обрезкой его не поднять.

Проверить текущее состояние: `npm run sprites:check`.

## Что меняется в производстве

- **Одна поза — одно изображение.** Никаких листов с сеткой поз.
- **Портретный кадр от 1024×1536, желательно 1440×2160.** Фигура занимает не меньше
  92% высоты кадра. Целевая высота фигуры — **от 1350 пикселей**, это порог проверки.
- Остальные требования — прежние, они уже дали нужный стиль:
  - полный рост целиком: макушка, волосы, руки, пальцы, обувь и подошвы внутри холста
    с безопасным прозрачным полем;
  - единая полуреалистичная рисовка визуальной новеллы, выразительная мимика, читаемый
    силуэт, анатомически естественные руки;
  - один и тот же человек во всех состояниях: одежда, причёска, аксессуары, пропорции
    и особенности внешности не меняются между позами;
  - настоящий прозрачный alpha-канал, без нарисованной шахматной подложки, текста,
    рамок и теней, обрезанных границей;
  - пять состояний: `neutral`, `happy`, `worried`, `surprised`, `determined`.

## Что делать с результатом

1. Сохранить как `assets/characters/generated/<герой>-<состояние>-v4.png`.
2. `npm run sprites:normalize` — обрежет прозрачные поля и выровняет долю фигуры в холсте,
   чтобы герой не менял размер при смене эмоции. Пиксели не масштабируются.
3. `npm run sprites:check` — покажет растяжение на сцене. Должно быть не больше 1.15.
4. Переключить импорты в `src/story/Sprite.tsx` с `-v3.png` на `-v4.png`.

Файлы `-v3.png` не удалять до полной замены состава: сцена берёт спрайты по имени,
и недостающая эмоция оставит героя без спрайта.

## Что исправить по сравнению с v3

- **Мира и Соня одеты почти одинаково** — обе в графитовой рубашке-оверсайз с красной
  подкладкой манжет. В v4 развести: Мире оставить рубашку, Соне дать другой верх
  (см. её карточку).
- **Павел** в позе `determined` вышел заметно ниже остальных своих поз. Рост фигуры
  должен совпадать во всех пяти кадрах героя.
