# Учебный план курса Pandas

Курс переписан целиком. Прежняя версия — 117 миссий, из которых 96 были выводом
`scripts/generate-planned-courses.mjs`: пять одинаковых слотов на каждую тему и
практика по шаблону. Идентификаторы `PDA-001..117` сняты, их судьба описана в
`knowledge/migrations/mission-id-aliases.json`.

Порядок блоков повторяет порядок работы с данными, а не порядок разделов
документации: сначала таблица как объект, потом чтение и первый взгляд, потом
выбор и фильтрация, и только после этого пропуски, дубликаты и соединения.
Группировка стоит после того, как строковые категории приведены к единому виду,
— иначе первая же сводка разносит один город по четырём строкам.

Функции появляются там, где они нужны задаче, а не для инженерности: `def` в
курсе не требуется ни в одной проверке.

Дело курса — «Семь версий одной таблицы»: после цепочки преобразований строки
исчезают, типы меняются, а итог нельзя воспроизвести. Каждый блок закрывает
одну из причин этого: молчаливая потеря строк при очистке (`PDA-1503`),
размножение при соединении (`PDA-2304`), запись в результат отбора
(`PDA-2803`), перезапись одного имени на каждом шаге (`PDA-2804`).

Аудит `npm run api:audit` по всем десяти правилам: 0 находок. Классификация —
`AUTHORED_REAL`.

Всего: 121 миссий, из них 62 с рабочим файлом.
