# Учебный план курса NumPy

Курс переписан целиком. Прежняя версия — 48 миссий, из них 32 кодовые, и во
всех тридцати двух редактор открывался пустым: практики в курсе не было ни
одной. Идентификаторы `NPY-001..047` и `NPY-BOSS-01` сняты, их судьба описана в
`knowledge/migrations/mission-id-aliases.json`, отметки о прохождении снимаются
миграцией состояния.

Порядок блоков задан так, чтобы каждая сущность вводилась отдельно: сначала
понятие внешней библиотеки, потом импорт, потом псевдоним, и только потом
первая функция библиотеки. Одна новая сущность на миссию; перед каждой
самостоятельной записью стоит ступень «измени» или «дополни».

Дело курса — «Модель, которая знала слишком много»: матрица признаков на 850
тысяч строк, подозрительно высокая метрика и три ошибки, ни одна из которых не
вызывает исключения. Авторские сцены привязаны к тем миссиям, где эти ошибки
разбираются: перепутанная ось — `NPY-1405`, переполнение целого — `NPY-2303`,
испорченный срезом оригинал — `NPY-2204`.

Аудит `npm run api:audit` по всем десяти правилам: 0 находок. Классификация —
`AUTHORED_REAL`.

Всего: 109 миссий, из них 54 с рабочим файлом.
