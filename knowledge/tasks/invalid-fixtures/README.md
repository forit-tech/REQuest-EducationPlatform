# Заведомо невалидные задания

Эти задания нарушают правила намеренно. Они нужны, чтобы доказать, что валидатор
ловит нарушение, а не только пропускает хороший контент.

Валидатор качества их не проверяет: они лежат вне периметра `knowledge/tasks/`,
который считается новым контентом. Проверяет их `npm run quality:test`, и он же
падает, если какое-то из этих заданий вдруг перестало нарушать своё правило.
