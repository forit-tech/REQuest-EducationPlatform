# REduQuest Content Factory v1

Content Factory создаёт оригинальные русскоязычные миссии из проверенного factual digest. Она не импортирует и не пересказывает один чужой урок.

## Конвейер

1. Topic Specification
2. Source Collector
3. Fact Digest
4. Curriculum Designer
5. Mission Author
6. Dataset Generator
7. Test Generator
8. Execution Validator
9. Technical Reviewer
10. Russian Editor
11. License / Provenance Check
12. REduQuest Content

## Классы источников

- `GROUNDING` — официальная документация, стандарты и эталонные примеры. Используется для проверки фактов и API.
- `ADAPTABLE_OER` — материалы, которые разрешено адаптировать с соблюдением лицензии и атрибуции.
- `REFERENCE_ONLY` — UX-паттерны и материалы без подходящей или ясной лицензии. Их содержание не переносится в REduQuest.

## Обязательные свойства миссии

- минимум два источника и factual digest;
- оригинальные сюжет, задания, датасеты и проверки REduQuest;
- минимум два разных действия ученика;
- применение или production-поворот после распознавания понятия;
- исполняемые проверки датасета и эталонного результата;
- техническое ревью, русская редактура и лицензионная проверка;
- технические термины сопровождаются русским объяснением.

## Проверка

```bash
npm run content:validate
```

Сборка приложения также запускает проверку автоматически. Миссия с отсутствующим источником, несовпадающей схемой CSV, несуществующим эталонным значением или незавершённым review gate не попадёт в production-сборку.
